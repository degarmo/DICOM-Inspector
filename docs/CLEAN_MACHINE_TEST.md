# Clean-machine test checklist (Windows)

Use this before releasing an installer. It shows the installed app works on a
Windows 10/11 machine with **no Python and no Node.js**, fully offline, and
that uninstalling leaves nothing behind.

CI already runs an automated subset of this on every build
(`build/smoke_test_installer.ps1`): a silent install, the engine run with Python
off PATH, an app launch, and a silent uninstall. This checklist covers what
needs a person: the installer pages, the UI, report export and SmartScreen.

## 1. Prepare (on the build machine)

1. Build the installer: `pwsh ./build/build_windows.ps1`.
2. Create a folder, for example `C:\dicom-inspector-test`, containing:
   - `release\DICOM-Inspector-Setup-0.1.0.exe`
   - the fixture pairs from `engine\tests\fixtures\` (generated by the build):
     `05_private_block_a.dcm`, `05_private_block_b.dcm`,
     `09_not_dicom_a.dcm`, `09_not_dicom_b.txt`.
     They are synthetic; no real patient data.

## 2. Start a clean machine

**Windows Sandbox** (Windows 10/11 Pro or Enterprise; enable "Windows Sandbox" in
*Turn Windows features on or off*). Save this as `dicom-inspector-test.wsb` and
double-click it. Networking is disabled, which also proves the app needs none.

```xml
<Configuration>
  <Networking>Disable</Networking>
  <MappedFolders>
    <MappedFolder>
      <HostFolder>C:\dicom-inspector-test</HostFolder>
      <SandboxFolder>C:\Users\WDAGUtilityAccount\Desktop\test</SandboxFolder>
      <ReadOnly>true</ReadOnly>
    </MappedFolder>
  </MappedFolders>
</Configuration>
```

**Or a fresh VM** with a new Windows 10/11 image, no Python and no Node.js
installed. Disconnect its network adapter after copying the test folder in.

## 3. Checklist

| # | Step | Expected | Pass |
| - | ---- | -------- | ---- |
| 1 | In PowerShell, run `python -c "print(1)"` and `node -v`. | Neither runs: not found, or the Microsoft Store alias opens instead. | [ ] |
| 2 | Run `DICOM-Inspector-Setup-0.1.0.exe`. | Unsigned builds show SmartScreen "Windows protected your PC". Choose **More info** > **Run anyway**. Signed builds show the publisher. | [ ] |
| 3 | Install-mode page. | "Only for me" is selected by default. No admin prompt for this choice. | [ ] |
| 4 | Directory page, then install. | Default folder is `%LOCALAPPDATA%\Programs\DICOM Inspector`. | [ ] |
| 5 | Finish page. | "Run DICOM Inspector" is checked. "Create a desktop shortcut" is **unchecked**. Check it, then Finish. | [ ] |
| 6 | Start menu and desktop. | A "DICOM Inspector" Start menu entry and a desktop shortcut, both with the app icon. | [ ] |
| 7 | Launch the app. | The main window opens. No error screen, no console window. | [ ] |
| 8 | Drop `05_private_block_a.dcm` on File A and `05_private_block_b.dcm` on File B (or use Ctrl+O / Ctrl+Shift+O). Press Ctrl+Enter. | **No console window flashes.** Summary: 4 priority mismatches, Identical 32, Only in B 4, Total 36. Both file panels show "Secondary Capture Image Storage" and "Explicit VR Little Endian". The Priority group lists 4 private rows with creator `SYNTHETIC_VENDOR_1`. | [ ] |
| 9 | Compare `09_not_dicom_a.dcm` with `09_not_dicom_b.txt`. | Inline error "Not a DICOM file: File B (09_not_dicom_b.txt)". No crash, no blank screen. | [ ] |
| 10 | Compare the `05` pair again. Choose HTML, press Ctrl+E and save to the Desktop. | "Saved dicom-diff-....html". Opening it in Edge shows files, summary, priority mismatches and the footer "Generated locally by DICOM Inspector. No data left this machine." | [ ] |
| 11 | Choose PDF and export again. | The PDF opens in Edge with the same content. | [ ] |
| 12 | Check the install folder. | It contains `DICOM Inspector.exe`, `THIRD_PARTY_NOTICES.txt` and `resources\engine\dicom_inspector_engine.exe`. | [ ] |
| 13 | Missing-engine screen: close the app, rename `resources\engine` to `engine.bak`, launch again. | A screen titled "Engine not found — reinstall DICOM Inspector". No crash. Rename the folder back afterwards. | [ ] |
| 14 | Close the app. Uninstall from **Settings > Apps > Installed apps > DICOM Inspector**. | The uninstaller completes. | [ ] |
| 15 | Confirm removal. | These are all gone: `%LOCALAPPDATA%\Programs\DICOM Inspector`, the Start menu entry, the desktop shortcut, `%APPDATA%\DICOM Inspector`, and the "DICOM Inspector" entry in Installed apps. | [ ] |
| 16 | Optional: all users. Run the installer again and choose "Anyone who uses this computer". | A UAC prompt appears. It installs to `C:\Program Files\DICOM Inspector`. Repeat 7-8, then uninstall and confirm the folder is gone. | [ ] |

Record the Windows version and build, the installer SHA-256 printed by
`build_windows.ps1`, and the date with the results.
